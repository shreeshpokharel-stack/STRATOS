# 🚀 STRATOS

STRATOS is a personal digital dashboard built using Flask, HTML, CSS, and JavaScript.

It acts as a centralized command center for AI tools, sports resources, music platforms, social media, productivity tools, and utility features.

---

## ✨ Features

### 🤖 AI Hub
- ChatGPT
- Grok
- Gemini
- Claude

### ⚽ Sports Hub
- LiveSports077
- SofaScore
- YosinTV

### 🎵 Music
- Spotify Integration

### 🌐 Social Media
- YouTube
- Facebook
- Instagram

### 📝 Productivity
- Notes System (Local Storage)
- Search Functionality
- Theme Switcher

### 🧮 Utilities
- Calculator
- World Clocks
- Live Digital Clock

---

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/STRATOS.git
```

Install Flask:

```bash
pip install flask
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
